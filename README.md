# 🧰 SEU劳动教育课程推送助手

> 东南大学劳动教育选课神器！
> 常驻后台自动盯课，发现新课程第一时间通过微信 / 桌面通知你，再也不用守着页面刷新。

- 安装包：`SEU劳动教育课程推送助手-1.0.0-setup.exe`（见 `release/`）
- 这是一个**独立后台程序**（自己的进程 + 托盘图标），不需要保持浏览器标签页打开。

---

## ✨ 功能亮点

- **后台静默监控**：住在托盘里，关掉窗口也照常紧盯选课页。
- **自动登录**：填写一次账号密码，程序自动维持登录状态。
- **双通道通知**：Windows 桌面通知 + 微信（PushPlus），发现新课立即推送。
- **地点筛选**：只接收指定校区 / 地点的课程。
- **类型筛选**：按生活劳动 / 服务劳动 / 生产劳动挑选想收到的课程。
- **内置浏览器**：登录与选课都在程序内完成，打开即已登录。
- **每日汇总**：每天晚上推送一份当天监控情况。
- **开机自启**：重启电脑后自动恢复监控（可随时关闭）。
- **自动选课（可选，默认关闭）**：符合筛选条件的课程自动提交。

## ⬇️ 安装

1. 下载并运行安装包 `SEU劳动教育课程推送助手-1.0.0-setup.exe`。
2. 按提示完成安装（可自选安装目录），安装完成后程序会自动启动。
3. 首次运行会弹出**设置向导**，跟着走就行：
   **账号** → **筛选** → **通知** → **登录** → **完成**。

> 首次登录（或更换网络环境时）可能需要短信验证码，在向导里点「打开登录窗口」，
> 在弹出的内置浏览器里手动完成一次即可，之后长期免打扰。
> 检测到登录后，程序会自动转入后台监控，无需再手动确认。

---

## 🧭 日常使用

托盘图标（右下角）提供所有操作：

- **用内置浏览器打开选课页**：已登录，可直接选课。
- **打开登录页 / 重新登录**：登录态失效时用。
- **立即抓取一次**：不想等，马上看一眼有没有新课。
- **查看日志 / 打开 config.json / 设置向导**。
- **开机自启**、**自动选课**：直接勾选或取消。
- **清除登录态（重新登录）**、**退出**。

点击「发现新课程」的桌面通知，会直接打开选课页。

## 🔔 微信推送（PushPlus）

1. 访问 [PushPlus](http://www.pushplus.plus)，微信扫码登录。
2. 复制你的 **用户Token**。
3. 在设置向导的「通知」页填入，并打开微信推送开关即可。

> 💡 可能需要向 PushPlus 平台支付 1 元以激活微信推送功能。

## ⚙️ 配置

绝大多数设置都能在**设置向导**里完成，无需手动改文件。

配置与数据保存在 `%APPDATA%\SEU劳动教育课程推送助手`（卸载不会删除）。
偏好手动编辑的话，可直接改其中的 `config.json`，保存即生效。

| 字段 | 说明 |
|---|---|
| `credentials.username` / `.password` | 一卡通号与统一身份认证密码，仅保存在本机 |
| `filters.locations` | 地点关键字；开课地点**包含**任一关键字即命中，留空不筛 |
| `filters.categories` | 劳动类型**黑名单**；与黑名单完全匹配即排除，留空不筛 |
| `schedule.refreshIntervalMs` | 监控轮询间隔（默认 3 分钟） |
| `push.pushplus.token` | 微信推送 Token，留空则只用桌面通知 |
| `behavior.autoLaunchAtLogin` | 开机自启 |
| `behavior.autoSelect` | 自动选课（默认 `false`） |

> 类型筛选在向导里是「勾选想收到的」白名单，写回 `config.json` 时会自动转成黑名单，无需你操心。

## ❓ 常见问题

- **登录不上 / 要短信验证**：在向导或托盘里打开登录窗口，手动完成一次即可。
- **收不到通知**：检查系统是否开启了「专注助手 / 勿扰模式」；微信通道确认 Token 正确。
- **想换校区或类型**：托盘「设置向导 / 检查配置」，在第 3 步「筛选」里改。
- **旧版的篡改猴脚本**：已归档到 `archive/` 目录，不再维护，请使用本程序。
